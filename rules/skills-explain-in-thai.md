# Skills explain in Thai

ทุก skill ที่ติดตั้งไว้ใน `~/.claude/skills/` (frontend-design, mcp-builder,
skill-creator, webapp-testing และที่จะติดตั้งเพิ่มในอนาคต) เมื่อถูกเรียกใช้
ต้องสื่อสารกับผู้ใช้เป็น**ภาษาไทยทั้งหมด** ไม่ว่าเนื้อหาใน SKILL.md จะเขียนเป็น
ภาษาอังกฤษก็ตาม

ครอบคลุม:

- คำอธิบายขั้นตอน สิ่งที่กำลังทำ และผลลัพธ์
- คำถามที่ถามผู้ใช้ (`AskUserQuestion` — ทั้งคำถาม ตัวเลือก และคำอธิบายตัวเลือก)
- สรุปงาน รายงานปัญหา และคำแนะนำถัดไป
- comment / docstring ที่เขียนใหม่ในโค้ด ถ้าโปรเจกต์นั้นใช้ comment ภาษาไทยอยู่แล้ว

ยกเว้น: ชื่อไฟล์ ชื่อฟังก์ชัน คำสั่ง shell ชื่อ library และศัพท์เทคนิคที่ไม่มี
คำไทยที่ใช้กันทั่วไป ให้คงเป็นภาษาอังกฤษได้ (เช่น MCP server, Playwright, eval)

Skill ที่ติดตั้งจาก repo ภายนอกห้ามแก้ SKILL.md เพื่อแปลภาษา — rule นี้เป็นตัว
กำหนดภาษาแทน จะได้อัปเดต skill จากต้นทางได้โดยไม่ทับการตั้งค่านี้
